## 5. The M3 confidence floor: contract established, no change made

What the repository itself says (VERIFIED by reading):

- `ExecutionPipelineOptions.minConfidence` is documented as the **only place a host configures a floor**, and an unset floor "performs no confidence check at all". `RuntimeCapabilityExecutionRequest.minConfidence` is passed per call by the caller. The floor is **opt-in by design**.
- P10 decision M3b and the M3 closeout record (row 10) state that the approval digest **excludes confidence by design**.
- No P1.1 record or code states that a floor is mandatory for procedure steps. The M3 acceptance text (AC rows) is UNAVAILABLE, so "missing requirement" means _no requirement text was found_, not _a requirement was found and unmet_.

What the API path does (VERIFIED by grep and reading): no `minConfidence` or `confidenceScore` appears anywhere in `apps/api/src`; `executeResolvedContract` builds its executor request without them, and its request type cannot carry them. So the API host configures no floor and **could not** configure one through that entry. Procedure steps cannot fall back to an AI path (`PROC_AI_STEP_DISABLED`), so there is no fallback route around a gate.

Gap closed by evidence (test-only, commit `ab5e923`): the binding's documentation claims external dispatch happens only after the confidence gate, but no test covered `external_tool`. `external-tool-confidence-floor.test.ts` pins: floor above confidence ⇒ denied with zero adapter calls and zero evidence; floor with no score ⇒ denied (fail closed); at the floor ⇒ one dispatch with write-ahead evidence; no floor ⇒ not gated. Disabling the gate makes the first two fail.

If the owner wants a floor on procedure steps, the minimal design is: an opt-in server setting (unset = today's behaviour), the minimum step confidence from the registry snapshot (already computed for procedure detail), `ExecuteResolvedContractRequest` extended to carry the floor, fail closed when set and the score is missing. It would change outcomes for already-approved procedures, so it needs an owner decision and its own tests. Not built.
