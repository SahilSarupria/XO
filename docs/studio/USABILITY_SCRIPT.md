# Studio usability script

For a session with a person who has not used XO. Nobody has run this yet: the first real sessions are an owner item (see the readiness report). Run it with a real colleague, not a developer, and record where they stop, hesitate, or say something unexpected.

## Before you start

- A fresh workspace with the operator's access key, one real document of the person's own (a checklist, a how-to, an agreement they work from), and, if they will try sending, a sending account they own.
- Do not explain XO. Say only: "Please try to get this document's work done with XO. Think aloud. I will not help unless you are stuck for two minutes."
- Phone and laptop both; run half the sessions on each.

## Tasks (read one at a time, in this order)

1. **Sign in** and say what you think this is. (Sign-in page, Home.) Watch: do they find the access key or the browser sign-in without help?
2. **Add your document** and say what XO found. (Sources, "What XO found".) Watch: do "Yes, that is right" and "No, that is not right" make sense; do they read the findings or skip them?
3. **Set up a workflow** from it and give it a name you would recognise. (Work, New workflow, the workflow's own page, Rename.)
4. **Check it is ready, then start it** for the first time. (Check before starting, Start this workflow.) Watch: do they understand what "Check before starting" is for?
5. **Find what needs you.** A decision is waiting; say what it is and decide it. (Inbox: on a phone, the list then the item.) Try a step marked as a task ("Mark done / Not done") and one with actions (Approve / Reject).
6. **Say what happened.** Open the run, tell me what XO did and why. (Activity, a run's page, "Why XO did this".)
7. **Make it repeat.** Run it every week, then switch it off. (Schedule tab.) Watch: do they notice that scheduled runs still wait for approval?
8. **Stop everything** in an emergency, then undo it. (Settings, Operations; the banner "See what is stopped".)
9. **Invite a colleague** as someone who can only look. (Settings, Members, the link; hand the link over; the colleague opens it.)
10. **Ask XO** "What is waiting for me?" and then "Why did the last run stop?" from a workflow's own page. (The Ask box.)

## What to record for each task

Done without help / done after a hint / not done. The first wrong click. Any word they stopped on. Anything they said they expected to happen that did not.

## Words to listen for

Any time they say "what does X mean" about: Run, Item, Source, Inbox, Check before starting, Knowledge, Records. Those words are the glossary; a stumble is a copy fix.

## Pass bar to aim for (a guide, not a measurement)

Eight of the ten tasks done without help by at least four of five people, and nobody believes XO did or sent something it did not.

## What this script cannot tell you

How XO behaves on documents unlike the sample, under real load, or with real email accounts. It tests whether the screens are understandable.
