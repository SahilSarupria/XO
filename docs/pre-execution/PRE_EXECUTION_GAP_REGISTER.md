# Pre-execution gap register

Each gap was verified by reading the code at `4a9837b`; file and line references are to that commit.

**Status values:**

- `open`: not started.
- `in progress`: work has started.
- `implemented`: the code is written.
- `verified`: tests and end-to-end evidence pass. A gap is marked verified only then.
- `deferred`: out of scope or owner-gated, with the reason given.

**Columns:**

- **Fix** names the pre-execution PR (`PX-n`) that delivers the correction.
- **Owner** marks a decision that needs owner ratification (ADR 0029 decision 17).

Severity:

| Level | Meaning                                                                |
| ----- | ---------------------------------------------------------------------- |
| S1    | Can cause a false-ready, silent loss, or crossing of a trust boundary. |
| S2    | Wrong or divergent result.                                             |
| S3    | Missing capability or reporting.                                       |
