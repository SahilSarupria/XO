One integration owner (Claude) edits the shared contracts. Read-only agents may do research. Code changes are serialized.

## Rules for every PR

- **Before opening a PR:**
  - Run the full build, tests, Studio tests, lint, format, typecheck and `npm run eval -- --check`.
  - Refresh any benchmark baseline that moves under control, with every difference given a disposition.
- **When a stage lands:**
  - Update the gap register rows it touches. A row is marked `verified` only with test evidence.
  - Change no runtime execution semantics. Leave the frozen roadmaps (`specs/`, `docs/ROADMAP.md`) unedited.
- **Thresholds:** keep each threshold as a proposal until the owner ratifies it. Until then, the conservative behaviour applies.
