Connect

This page talks to /api/*, which server.mjs proxies straight through to your real apps/api process (default http://127.0.0.1:4000) — same origin, so there's nothing to configure on the API side. Every route except /health and /openapi.json requires an API key issued via apps/api/scripts/manage-keys.ts. See the README for the exact commands.

API Key

Stored only in this browser's localStorage, sent as Authorization: Bearer <key>.
